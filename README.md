# 🛒 ShopEasy – JSP User Management System

A Java-based web application built using JSP, HTML, CSS, and JavaScript. The project focuses on user registration, authentication, profile management, and personalized user interface preferences.

## 🔗 Repository

[ShopEasy – JSP User Management System](https://github.com/MohammedYa/ShopEasyJSPUserManagementSystem)

## ✨ Features

- **User Registration:** Create accounts with personal information.
- **User Login:** Authenticate registered users.
- **User Profile:** Display user information after successful login.
- **Language Preferences:** Support Arabic, English, and German language selection.
- **Theme Customization:** Dark Mode and Light Mode.
- **Session Management:** Manage user sessions and store registered users.
- **Input Validation:** Validate user information during registration and login.

## 🛠️ Technologies Used

- Java
- JavaServer Pages (JSP)
- HTML5
- CSS3
- JavaScript
- Apache Tomcat

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/MohammedYa/ShopEasyJSPUserManagementSystem.git
   ```

2. Import the project into Eclipse IDE.
3. Configure Apache Tomcat Server.
4. Run the project on the server.
5. Open the application in your browser.
